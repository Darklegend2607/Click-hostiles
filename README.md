# ClickHostiles
Fabric mod for Minecraft 1.21.1. Sneak + right-click a hostile mob with an empty hand to pick it up as a head. Right-click a block with that head to place the same mob back.
Mobs without a vanilla head get a player head that looks like the mob (textures from the MinecraftHeads database).
Wither, Ender Dragon and Warden can't be picked up.
